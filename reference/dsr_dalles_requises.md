# Selectionner les dalles intersectant une emprise

Selectionner les dalles intersectant une emprise

## Usage

``` r
dsr_dalles_requises(catalogue, emprise)
```

## Arguments

- catalogue:

  Sortie de
  [`dsr_catalog()`](https://pobsteta.github.io/dessertR/reference/dsr_catalog.md).

- emprise:

  Objet `sf` ou `sfc`.

## Value

Le catalogue restreint aux dalles concernees.
