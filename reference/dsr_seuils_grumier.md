# Seuils d'aptitude au grumier par defaut

Jeu de seuils *indicatif* pour
[`dsr_trafficability()`](https://pobsteta.github.io/dessertR/reference/dsr_trafficability.md),
a **caler avec le gestionnaire** (BRIEF section 3.7) : ils ne sont
jamais figes en dur.

## Usage

``` r
dsr_seuils_grumier()
```

## Value

Une liste : `largeur_min` (m), `pente_max` (m/m), `rayon_min` (m),
`gabarit_min` (m).
